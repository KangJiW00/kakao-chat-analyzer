# kakao-chat-analyzer

현장 카카오톡 대화를 GitHub Pages 앱 화면에서 직접 업로드·붙여넣기해 분석하는 정적 웹앱입니다. 외부 CDN, 빌드 도구, 백엔드 없이 단일 `index.html`로 동작하며, AI나 Porter.ai 모델/API를 사용하지 않고 브라우저 JavaScript의 키워드·정규식 규칙으로 분석합니다.

## 이번 수정 사항

- 날짜 구분선 `--------------- 2026년 8월 21일 금요일 ---------------`을 인식하고 다음 메시지의 날짜로 상속
- `[정민] [오전 12:03] 내용` 형식의 작성자·시간·내용 파싱
- `2026. 8. 21. 오전 2:03, 이름 : 내용` 형식 파싱
- `[날짜] 이름 : 내용`, ISO 날짜, CSV형 행 등 일반 변형 지원
- 여러 줄 메시지를 하나로 결합
- UTF-8 BOM 제거, UTF-8 우선 및 EUC-KR/CP949 대체 디코딩
- 메시지의 `라인 :`, `공정 :`을 우선 인식하고 패턴으로 보조 추정
- 24개 라인 기준정보와 정규식 내장
- 구체 라인을 먼저 검사하고 개별 정규식마다 try/catch 처리
- 결과에 날짜, 시간, 작성자, 라인, 공정, 카테고리, 고장부위, 고장원인, 조치유형, 조치내용, 소요시간, 원문, 조치결과, 상태 제공
- 차트와 자동 종합분석의견 추가
- 파싱 실패 시 행 수, 인식 메시지 수, 미매칭 안내 표시

## 지원 기능

- TXT 파일 선택·드래그앤드롭·붙여넣기·대표 샘플
- KPI: 총 건수, 고장 건수, 미조치, 라인 수, 공정 수, 평균 조치시간
- 차트: 공정별 발생, 고장부위별, 시간대별 히트맵, 조치유형별, 알람유형별, 고장원인별, 고장라인별
- 차트 수치·범례 및 데이터 없음 안내
- 자동 종합분석: 상위 라인·공정·부위·원인·시간대·미조치 비율
- 라인·공정·카테고리·작성자·상태 필터, 검색, 정렬, 페이지네이션, 전체 보기
- 상세 모달, 상태 변경, 조치 메모
- 분석 이력 localStorage 저장·복원·삭제
- JSON/CSV 내보내기
- 라인/공정/카테고리 패턴 관리 및 라인 추가·수정·삭제

카테고리는 `고장`, `반복문제점`, `반복문제`, `이슈사항`, `청소`, `정지`, `불량`, `기타`를 지원합니다.

## 대표 자체 점검 입력

앱의 `대표 샘플` 버튼에는 다음 입력이 들어 있습니다.

```text
--------------- 2026년 8월 21일 금요일 ---------------
[정민] [오전 12:03] 에어블로우 반출,반입 티칭 및 pp로더 그리퍼 조치후 가동
[김철수] [오전 09:15] LX3 1차 20-2공정 탑도어 알람 발생, 센서 교체
2026. 8. 21. 오전 10:20, 홍길동 : KA4 10공정 불량 발생 원인 확인 및 조치완료
```

세 메시지 모두 작성자·시간·내용으로 인식되며, 날짜 구분선의 `2026-08-21`이 첫 두 메시지에 상속됩니다. LX3 1차와 KA4 라인이 매칭되고, 알람·불량·조치완료 등의 규칙이 적용됩니다.

## GitHub Pages 배포

Repository URL은 다음 저장소를 사용합니다.

```text
https://github.com/KangJiW00/kakao-chat-analyzer
```

1. 저장소 루트에 `index.html`과 `README.md`를 업로드합니다.
2. GitHub 저장소의 **Settings → Pages**로 이동합니다.
3. **Deploy from a branch**를 선택합니다.
4. `main` 브랜치와 `/ (root)`를 선택해 저장합니다.
5. Pages 배포가 완료되면 다음 URL을 사용합니다.

```text
https://kangjiw00.github.io/kakao-chat-analyzer/
```

이 앱은 루트 단일 HTML이고 별도 라우팅을 사용하지 않아 새로고침 경로 404를 피합니다.

## 애플리케이션 메뉴 연결

- URL 연결 또는 웹사이트 연결 방식: `https://kangjiw00.github.io/kakao-chat-analyzer/`
- Git 저장소 연결 방식: `https://github.com/KangJiW00/kakao-chat-analyzer`

애플리케이션 좌측 메뉴에서 외부 앱·웹사이트·URL 등록 메뉴를 열고 위 GitHub Pages URL을 등록합니다. 등록된 앱을 열면 채팅창에서 별도 URL을 받는 것이 아니라 앱 화면 자체에서 TXT 파일을 업로드하거나 내용을 붙여넣고 `분석 실행`을 누릅니다.

플랫폼에서 Git 저장소 연결 중 `redirect_uri` 또는 OAuth 오류가 발생하면 앱 코드가 아니라 애플리케이션 플랫폼 관리자 측 GitHub OAuth callback/redirect URI 설정 문제일 수 있습니다. 이 경우 플랫폼 관리자에게 등록된 OAuth redirect URI와 실제 접속 주소를 확인해야 합니다.

## localStorage 제한사항

분석 원문, 결과, 설정, 이력은 브라우저 `localStorage`에 저장됩니다. 따라서 동일 브라우저·동일 기기에서만 유지되며, 다른 브라우저·기기·시크릿 모드와 자동 공유되지 않습니다. 사이트 데이터 삭제 시 이력이 사라질 수 있고, 백엔드가 없으므로 팀원 간 중앙 이력 공유는 지원하지 않습니다.
